# Agency logos

The "Proven Across Government" section on the Marketplaces page shows a logo for
each marketplace sponsor. Drop approved logo files here using these exact names:

| File | Agency |
|---|---|
| `darpa.png` | Defense Advanced Research Projects Agency |
| `cdao.png` | Chief Digital and Artificial Intelligence Office |
| `air-force.png` | Department of the Air Force |
| `aal.png` | Army Applications Laboratory |
| `iarpa.png` | Intelligence Advanced Research Projects Activity |

Until a file exists, that card falls back to the agency name as text, so the
section never looks broken.

## File guidance

- **Format**: PNG with a transparent background (SVG also works, but the paths
  in `marketplaces/index.html` would need the extension changed).
- **Background**: the section sits on deep navy, so white or light monochrome
  versions read best. Full-color seals on a dark background often look muddy —
  if only full-color versions are approved, say so and the cards can be given a
  white chip behind each logo instead.
- **Size**: roughly 400–600px wide is plenty; logos render at up to 68px tall.
- **Approval**: only use official logo files that have been cleared for public
  use. Do not recreate or approximate government seals.
